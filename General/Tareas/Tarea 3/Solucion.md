## Respuestas

1. `0011 / 1011` → F(Z,X,Y) = X + ZȲ
2. `0011 / 1100` → F(Z,X,Y) = z̄X + Zx̄
3. `0111 / 0111` → F(Z,X,Y) = X + Y
4. `1001 / 1111` → F(Z,X,Y) = Z + Ȳ
5. `0011 / 1001` → F(Z,X,Y) = z̄X + ZȲ
6. `0111 / 1100` → F(Z,X,Y) = z̄X + Zx̄ + x̄Y
7. `1111 / 0111` → F(Z,X,Y) = Z̄ + X + Y
8. `1101 / 1011` → F(Z,X,Y) = Ȳ + z̄x̄ + ZX
9. `0001 / 1011` → F(Z,X,Y) = Xȳ + ZȲ + ZX
10. `1011 / 1000` → F(Z,X,Y) = x̄ȳ + Z̄X
11. `0111 / 0001` → F(Z,X,Y) = Z̄Y + XȲ
12. `1111 / 1011` → F(Z,X,Y) = Z̄ + X + Ȳ
